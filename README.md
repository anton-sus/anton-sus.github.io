# Weather Forecast Site

This is a simple weather forecast web application deployed on GitHub Pages. It allows users to search for a city and view the current weather conditions as well as a forecast chart.

🌐 **Start URL:** [https://anton-sus.github.io/src/](https://anton-sus.github.io/src/)

---

## Features

- Search for a city to get weather information.
- Display current temperature, wind speed, and city information.
- Show a chart of temperature and pressure for the forecast.
- Automatic update of the current date and time.
- Stores the last searched city in local storage.

---

## Functionality Overview

The main JavaScript features include:

- Handling search input visibility and events.
- Fetching city coordinates and weather data.
- Displaying temperature, wind speed, and city details.
- Creating a line chart for temperature and pressure using Chart.js.
- Updating and formatting the current date and time.
- Storing recent searches in the browser's local storage.

---

## Usage

1. Open the site: [https://anton-sus.github.io/src/](https://anton-sus.github.io/src/)
2. Click the **Search** button to show the search field.
3. Type the city name and press **Enter**.
4. View the current weather and the forecast chart.

---

## Technologies

- HTML, CSS, JavaScript
- Chart.js for forecast visualization
- Moment.js for date formatting
- Fetch API for weather data
